# Level 2 Submission Checklist

Use this checklist in order and tick each item before zipping your submission.

## A. Local Verification

- [ ] Install dependencies succeeded
- [ ] App runs locally on http://localhost:8080
- [ ] Build command succeeded: npm run build
- [ ] Build output generated in dist folder

## B. Functional Validation (Mandatory)

- [ ] Valid city search 1 works (example: Chennai)
- [ ] Valid city search 2 works (example: Bangalore)
- [ ] Invalid city search shows error state (example: InvalidCity987654)
- [ ] Current weather shows temperature
- [ ] Current weather shows condition
- [ ] Current weather shows wind
- [ ] Current weather shows humidity
- [ ] 7-day forecast visible with day, max temp, min temp, weather
- [ ] Recommendation cards visible

## C. GitHub and Cloudflare Flow

- [ ] Source pushed to GitHub repository
- [ ] Cloudflare Pages connected to GitHub repository
- [ ] Build command in Cloudflare set to npm run build
- [ ] Build output directory in Cloudflare set to dist
- [ ] First deployment completed successfully
- [ ] Live pages.dev URL opens in browser

## D. Evidence Screenshots (Take in this exact order)

1. Google AI Studio app/project screen
2. GitHub repository root showing source and README
3. Cloudflare Pages project build settings
4. Cloudflare Pages deployment success log
5. Live pages.dev home screen
6. Live search result for valid city 1
7. Live search result for valid city 2
8. Live invalid city result
9. Current weather details section visible
10. 7-day forecast section visible
11. Recommendation section visible

## E. Packaging

- [ ] All required screenshots saved
- [ ] README present in repository
- [ ] Zip name format applied: empid_emp_name_appbuilding_L2.zip
- [ ] ZIP uploaded to LMS
